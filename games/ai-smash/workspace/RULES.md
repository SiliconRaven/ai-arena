# 平台混战规则 sm-1.3

可调数值见 [rules.json](../rules.json)，每回合的观察也包含 `rules`。C++ 引擎在 [native/include/engine.hpp](../native/include/engine.hpp)，可复制到自己的程序目录做前向模拟。

长度单位是“格”，速度是“格／tick”，时间是 tick。x 向右、y 向上，小人的 `(x, y)` 是双脚中点。

## 目标

每局 4 人混战，一人 3 条命。伤害累积成百分比，伤害越高被打得越远。飞出边界（`stage.blast`）丢一条命、伤害清零，等 60 个 tick 后在上方重生，重生后 90 个 tick 内打不到。命用完出局。

第 3000 个 tick 之后，边界开始向内收缩，下边界不动。到第 t 个 tick，收缩量 s = (t − 3000) × 0.02，左右边界是 ±max(0.0, `stage.blast.x` − s)，上边界是 max(14.0, `stage.blast.top` − s × 0.9)。边界碰到你同样丢命；在击杀窗口内打中过你的对手记这次击杀，否则算自己掉下去。这是为了让拖时间的局也能结束，躲着不打到最后会被边界吃掉。

只剩一人还在场，或到第 1800 回合，对局结束。

- **名次**：还在场的排在出局者前面。还在场的先比剩余的命，再比谁的伤害低；出局的越晚越靠前；再相同比击杀，最后按种子打破平局。
- **单局得分**：`1 × (人数 − 名次) + 10 × 击杀数`。控制台将各局得分相加。

## 本地程序

完整仓库和选手包都使用 `games/ai-smash/workspace/my-bot/`。编辑其中的 `bot.cpp`，在控制台点「用自己的程序和陪练打」。也可以把 [baseline/](baseline/) 复制到其他文件夹，再在控制台填写该路径。编译器会编译目录顶层所有 `.cpp`，头文件可以放在子目录里。

## 程序

游戏使用 `sm-step-json-1` 协议。基准程序附带 SDK（`include/step_worker.hpp` 与 `include/json.hpp`）。最小程序如下。

```cpp
#include "include/step_worker.hpp"
using J = mini_json::Json;

int main() {
    return sm_step_worker::run([](const J& obs, J& memory) {
        J order = J::object{};
        return std::make_pair(order, memory);
    });
}
```

- 程序是常驻进程，全局变量在回合之间保留；进程被重启后只有 `memory` 还在。`memory` 写成 JSON 后不超过 32768 字节，只有这一回合成功才保存。
- 物理每秒 30 个 tick，程序每 3 个 tick 决策一次（一个回合）。
- 每次决策最多 60 毫秒，第一次（启动程序也算在里面）最多 1600 毫秒。超时或出错的回合按空指令处理；超时、格式错这类协议故障连续 3 次判故障出局。

## 观察

`obs` 字段：`turn`、`tick`、`seat`（你的座位）、`seed`、`turn_limit`、`rules`、`players`（每个座位一项）、`shots`（飞行中的光波和钩索）。

`players[i]`：

| 字段 | 含义 |
| --- | --- |
| `x` `y` `vx` `vy` | 位置与速度 |
| `facing` | 朝向，1 向右，−1 向左 |
| `grounded` `air_jumps` | 是否站在地上、还剩几次空中跳 |
| `damage` `stocks` `meter` | 伤害百分比、剩余的命、技能条（0 到 1.0） |
| `act` `phase` `phase_ticks` | 正在出的招、阶段（`idle` `charging` `windup` `active` `recover`）、这一阶段还剩几 tick |
| `charge` `dir` | 蓄力攻击已蓄的 tick、招式方向 |
| `hitstun` `gap` `hook_cd` | 硬直、出招间隔、钩索冷却的剩余 tick |
| `respawn` `invuln` `out` | 等待重生、无敌的剩余 tick，是否已出局 |

`shots[i]`：`id`、`owner`、`kind`（`wave` 或 `hook`）、`x`、`y`、`vx`、`vy`、`ttl`。

## 指令

`order` 是一个对象，各键都可省略，字段名写错或类型不对算协议故障：

```json
{"move": 1.0, "jump": true, "drop": false, "skill": "attack", "dir": [1.0, 0.0]}
```

- `move`：−1 到 1，左右移动。
- `jump`：回合第一个 tick 跳一次。地上起跳，空中用二段跳（1 次，落地恢复）。
- `drop`：站在薄平台上时往下穿。
- `skill`：这一回合要出的招。`dir` 是方向向量，省略时朝自己面对的方向。
- 能出招的时机是没在出招、`gap` 为 0、没在硬直中，技能条也够。不满足时这条指令什么也不发生。

## 招式

| `skill` | 技能条 | 说明 |
| --- | --- | --- |
| `attack` 攻击 | 0.0 | 前摇 4，判定 3，后摇 6，伤害 7.0 |
| `charge` 蓄力攻击 | 0.0 | 连续下这条指令就一直蓄，最多算 45 tick；不再下就松手，随时可以松。松手后前摇 8，后摇 16。威力随蓄力时间增加，蓄满时是 2.0 倍。短蓄的击飞倍率从 0.85 随蓄力进度提升，蓄力达到一半时回到 1 倍。蓄到 75 tick 自动松手。蓄力时下 `guard` 或 `blink` 就放弃蓄力，立刻防御或闪现，不出招也没有后摇。蓄力时被打中会中断，蓄的力作废 |
| `guard` 防御 | 0.0 | 连续下这条指令就一直举盾，最多 60 tick，撑满后要等 30 tick。挡得住打击和光波，挡不住抓投和钩索 |
| `blink` 闪现 | 0.2 | 朝 `dir` 高速移动 5 tick，期间打不到 |
| `uppercut` 上勾拳 | 0.25 | 把自己送上去，并把头顶的人往上打，也用来回场 |
| `slam` 下砸 | 0.2 | 只能在空中用，高速下落，把下方的人往下砸；砸空了自己也继续掉。反击接不住，防御挡得住。落地后由下砸造成的剩余硬直最多 15 tick |
| `wave` 光波 | 0.6 | 朝 `dir` 发一个飞行道具，飞行速度 0.75，最多飞 40 tick |
| `grab` 抓投 | 0.3 | 前摇 6，比攻击慢。抓中就朝 `dir` 扔出去。不算打击，防御和反击都接不住 |
| `counter` 反击 | 0.3 | 架势 12 tick，这期间被打中（下砸除外），就把这一招按 2.0 倍打回去；光波会被弹回去。没等到时后摇 16 |
| `hook` 钩索 | 0.4 | 飞行速度 0.7，最多飞 28 tick。钩到实心台就把自己拉过去，钩到人就把他拉过来，同时打断他的架势和防御。闪现能躲开。钩空后 150 tick 内不能再用 |

- 技能条每 tick 恢复 0.004。
- 任何招式结束后要等 4 tick（`gap`）才能出下一招。走动和跳跃不受限制。
- 被打时当前的招作废，并进入硬直（`hitstun`）。硬直结束时 `gap` 清零。

## 击飞

被打中时，速度 = `(knockback.base + knockback.scale × 打中后的伤害 ÷ 100) × 招式 power`，方向由招式决定。伤害计入后才算速度。

## 击杀

最后打中你的对手，在 300 tick 内记这次击杀（打击、光波、钩索、反击都算）。过了这段时间，或者没被人碰过，算自己掉下去，不给任何人记分。
